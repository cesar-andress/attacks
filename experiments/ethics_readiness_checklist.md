# Ethics-readiness checklist (human-participant experiments)

**Binding statement:** No human-participant experiment may be represented as executed until the required ethical and institutional conditions have been satisfied.

| Item | Required before human data | Notes |
|---|---|---|
| Institutional ethics review | yes | Follow local IRB/REC rules |
| Informed consent | yes | Role-appropriate |
| Participant information sheet | yes | Aims, burdens, voluntary nature |
| Withdrawal rights | yes | Without penalty |
| Professional-role risks | assess | Especially school-safety/police staff |
| Data minimisation | yes | Participant IDs in analysis files |
| Anonymisation plan | yes | |
| Secure storage | yes | **Not** public GitHub for sensitive data |
| Retention schedule | yes | |
| Publication of derived data | plan | Disclosure review for open text |
| Expert conflicts of interest | capture | EXP-05 field |
| Organisational identifiability | avoid | Prefer synthetic or heavily abstracted |
| Sensitive security information | minimise | No materials that materially increase vulnerability |
| Dual-use risk | assess | Especially Domain B / detection content |
| Open-text handling | plan | May be identifying |

## Current repository status

- Public pack contains **synthetic** stimuli and **synthetic** demonstration responses only.  
- No consent records, names, emails, or real school identities are stored here.
