# Data-management plan — Experimental Development Pack

## PUBLIC (this repository)

- Instruments, protocols, schemas  
- Analysis code  
- Synthetic datasets and constructed stimuli  
- Codebooks / item registers  
- Metadata templates  
- Aggregate synthetic demonstration reports  

## RESTRICTED (never commit here)

- Consent records  
- Identities, contact details  
- Raw identifying open-text  
- Security-sensitive real school information  
- Identifiable organisational records  

## DERIVED PUBLIC (only if approved)

- Anonymised coded responses  
- Aggregate statistics  
- Disclosure-reviewed qualitative summaries  

## Storage rule

GitHub/public git is **not** an approved store for sensitive participant data. Use institutional secure storage for restricted classes.
