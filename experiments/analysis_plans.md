# Analysis plans (preregistration-ready sketches)

Distinguish: **feasibility sample** · **methodological pilot** · **confirmatory study**.  
Current repo evidence supports only **synthetic demonstration** analyses.

## EXP-01 Unitization

- Exact unit-count match to REFERENCE_ADJUDICATION (not ground truth)  
- Pairwise unit-count agreement  
- Qualitative taxonomy: over-segmentation, under-segmentation, boundary ambiguity  
- Minimum feasibility N (indicative): 3–5 coders × full case set  
- No fabricated power analysis  

## EXP-02 Coding decisions

- Raw agreement on rung, locus, support_present, selected demands  
- Disagreement classifier: rule_application / codebook_ambiguity / plausible_alternative / coder_mistake / missing_rule / benchmark_dependent / out_of_scope_branch_b  
- Confidence–accuracy calibration (descriptive)  
- **Krippendorff’s α** only when `pass_type=independent_human` for ≥2 coders  
- **Must not** compute/label empirical α for `simulated_procedural_second_pass`  
- Indicative methodological pilot N: 2–4 independent coders  

## EXP-03 Usability

- Item means/distributions; open-text theme counts  
- **No** Cronbach-α / factor claims with tiny samples  
- Feasibility N: all coders in a wave  

## EXP-04 Evidence layers

- Accuracy vs REFERENCE_ADJUDICATION  
- Confusion matrix across Layers 1–5  
- Flag systematic Layer2↔3 and Layer4↔5 confusions  
- Feasibility N: ≥10 participants if seeking stable confusion patterns (not confirmatory)  

## EXP-05 Content mapping

- I-CVI (relevance ≥3) per domain; S-CVI/Ave  
- Qualitative revision rules from comments  
- Expert-group contrasts only if N permits  
- Does **not** validate SLAPA as a field instrument  

## EXP-06 Synthetic assessment

- Domain assessability consistency  
- Evidence-layer citation distribution  
- Missing-information and unjustified-inference frequencies  
- **Forbidden:** total readiness score  
- Feasibility N: 3–6 assessors × cases  

## Stopping / revision rules

If disagreement concentrates on a rule, amend codebook/protocol with versioned log; do not “fix” agreement by changing keys post hoc without documentation.
