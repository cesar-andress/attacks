# EXP-04 — Evidence-Layer Classification Test

Assign each synthetic statement to exactly one layer:

1. Doctrinal content  
2. Local adoption  
3. Organisational capability  
4. Exercised performance  
5. Real-world outcome  

Common traps: policy ≠ capability; scheduled drill ≠ observed performance; good drill ≠ incident effectiveness.

Reference classifications are **REFERENCE_ADJUDICATION**.
