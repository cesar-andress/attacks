# EXP-02 disagreement taxonomy

Classify each disagreement as exactly one primary type:

| Code | Meaning |
|---|---|
| `rule_application` | Correctable misapplication of an existing clear rule |
| `codebook_ambiguity` | Rule/example insufficiently specified |
| `plausible_alternative` | Competing defensible readings |
| `coder_mistake` | Slip inconsistent with coder's other decisions |
| `missing_rule` | Gap requiring codebook amendment |
| `benchmark_dependent` | Needs AFN/comparator calibration (e.g. CF-02) |
| `out_of_scope_branch_b` | Detectability/BTAM material outside Branch A model |

Do not collapse all disagreement into coder error.
