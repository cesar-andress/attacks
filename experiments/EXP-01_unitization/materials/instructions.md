# EXP-01 — Unitization Challenge (instructions)

**Status:** designed; human execution not started  
**Stimuli:** synthetic constructed English sentences only  

## Task

For each case, decide how many **prescriptive elements (PEs)** are present and briefly note boundaries.

## Rules (summary)

- A PE is a discrete prescription, control, or assessment directive.  
- Rationale/statistics without prescription → 0 PEs.  
- Multi-action sentences may be one chained PE or multiple PEs; record your rule.  
- Cross-references still count as prescriptions.  

## Output

Use `responses/response_template.csv`. Set `pass_type=independent_human`.
