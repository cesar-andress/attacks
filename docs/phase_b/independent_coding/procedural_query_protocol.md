# Procedural-query protocol (during independent coding)

**Purpose:** Allow clarification of process without leaking answers.

## Allowed questions

- File format / schema issues  
- Which package version is authoritative  
- How to record uncodeable / missing text  
- Technical access to authorized PDF  

## Forbidden responses from PI/staff

- “This should be rung 4”  
- Comparative hints about FNSS vs school texts  
- Sharing the other coder’s values  
- Sharing BDD draft resolutions  
- Sharing qualification answer keys  

## Log

Record each query in `private/coder_admin/query_log.md` (gitignored): date, coder ID, question summary, response summary, answer-bearing? (must be no).
