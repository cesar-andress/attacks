# Independent coder — role description

**Status:** recruitment materials only — **no coder recruited**  
**Study:** RP-P1 documentary audit (protective-action executability engagement)

## Role

Code L2 prescriptive elements independently using the public codebook, for Phase-B benchmark calibration and later double-coding of the frozen corpus.

## Eligibility

- Able to read English (and French/Spanish if assigned those sources).  
- Willing to follow codebook rules over personal judgment.  
- No conflicting authorship interest in target frameworks under coding (declare COI).  
- Not the adjudication lead for the same units they code.

## Desired expertise (any one sufficient)

- Emergency management / school safety practice; or  
- Content analysis / qualitative coding experience; or  
- Accessibility / AFN / inclusive education familiarity.

## Workload (estimate)

- Training + qualification: ~4–8 hours.  
- Phase B (single comparator L1): depends on PE yield (plan for 1–3 working days).  
- Later corpus double-coding: per reliability policy (100% if small corpus).

## Independence requirements

- No viewing of other coder values before raw submission.  
- No discussion of case answers during raw coding.  
- Training cases ≠ Phase-B target cases.
