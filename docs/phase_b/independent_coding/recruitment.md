1. [`coder_role.md`](coder_role.md)  
2. [`coi_confidentiality.md`](coi_confidentiality.md)

## Process

1. PI identifies candidate(s).  
2. Candidate reviews role + COI/confidentiality; signs/declares.  
3. Candidate completes training package (synthetic).  
4. Candidate completes qualification exercise; scoring script applied.  
5. On pass: assign `CODER_*` ID; grant restricted source access for Phase B only.  
6. On fail: remediation or withdrawal.

## Withdrawal

Coder may withdraw at any time; raw files already submitted remain archived with coder ID only.
