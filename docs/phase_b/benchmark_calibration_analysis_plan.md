# Benchmark-calibration analysis plan

**Purpose:** assess codebook behavior on a function-based comparator — **not** prevalence.

## Targets

- Ladder discrimination (0–5)  
- Support-definition clarity (named plan vs generic attention)  
- Assessment vs testing vs revision  
- Locus (individual / subgroup / setting)  
- Function-based vs named-condition logic  
- Resolution of BDD-001…005

## BDD resolution template

| decision_id | Evidence needed | Pattern supporting provisional Phase-A stance | Pattern overturning it | Affects Phase-A recode? | Affects RQ4? |
|---|---|---|---|---|---|
| BDD-001 | Comparator text on drills/tests | Distinguishes realistic usability tests from familiarisation | Treats any drill as testing | yes if overturned | yes |
| BDD-002 | Mandatory vs optional learning loops | Optional revision allowed with force memo | Only mandatory revision = rung 5 | yes if overturned | yes |
| BDD-003 | Named plans vs recognition language | PEEP/PAI can be support | Only function-based wording counts | maybe | yes |
| BDD-004 | Setting catalogs | Setting ≠ automatic support | Setting implies support | yes if overturned | secondary |
| BDD-005 | Illustrative cases | Non-binding examples may still show revision | Examples never count | maybe | secondary |

**Decision authority:** PI + adjudicators after independent coding; log in amendment_log / BDD register.
