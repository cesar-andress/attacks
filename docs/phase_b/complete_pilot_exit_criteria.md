# Complete-pilot exit criteria

Machine table: `data/phase_b/complete_pilot_exit_criteria.csv`

## BENCHMARK_CALIBRATION = COMPLETED

Requires CPX-01…CPX-10, CPX-12, CPX-13, CPX-16 at minimum (authorized source, qualified independent coders, unitization+coding, reliability, adjudication, BDD resolved, codebook versioned, validators green, no silent substitution).

## COMPLETE_PILOT = COMPLETED

Requires benchmark calibration completed **plus** CPX-11 (Phase-A recode if needed), CPX-14 (pilot exclusion policy enforced), CPX-15 (prereg readiness review).

**Source acquisition alone does not close the pilot.**
