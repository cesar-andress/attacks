# Privacy and retention plan (coder administration)

## Data collected

Contact details; signed COI/confidentiality; compensation routing (if any); training/qual timestamps; coded IDs.

## Purpose

Recruit, onboard, qualify, and administer an independent coder.

## Access / storage

PI-controlled private store (`private/coder_admin/`, gitignored). Not in public git or Zenodo.

## Retention / deletion

Retain signed agreements and submission hashes for audit through manuscript acceptance + local policy minimum; delete contact details when no longer needed. Pseudonymize research-facing logs.

## Separation

Administrative PII never joins the analytical dataset. Publication excludes signatures, emails, pay details, and COI narratives.

## Incidents

Use confidentiality incident form; revoke access; do not publish incident personal data.
