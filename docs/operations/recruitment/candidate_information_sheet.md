# Candidate information sheet

**Study:** RP-P1 executability-engagement documentary audit  
**Archive:** https://doi.org/10.5281/zenodo.21711588

## Summary

You would independently code documentary guidance using a frozen codebook. The study measures how documents engage with protective-action executability. It does not measure real-world compliance or effectiveness.

## Process overview

1. Screening and independence/COI declaration  
2. Confidentiality agreement  
3. Training materials  
4. Qualification (max two valid attempts; no answer keys shared)  
5. If qualified: calibration / later corpus coding under sealed-access rules  
6. Reliability calculated before adjudication

## Materials you may receive (staged)

| Stage | Materials |
|---|---|
| Pre-screen | Public role description; this sheet |
| After COI+confidentiality | Training package |
| After training attestation | Qualification package (no key) |
| After READY only | Sealed target / calibration materials |

## Compensation and recruitment

Recruitment is by **direct contact**. Collaboration is **voluntary and non-remunerated** (no payment). Participation is not contingent on qualification pass/fail, coding results, or reliability outcomes (UCW-003 RESOLVED).

## Data we store about you

Contact details and signed forms are stored in private admin space, not in the public repository. Research outputs use a pseudonymous coder ID.

## Questions

Procedural questions only; case answers will not be provided during independent coding.
