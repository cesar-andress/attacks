# Role-based material-release matrix

Release only after the listed gate is satisfied. Restricted materials never precede prerequisites.

| Material | Public / Restricted | Earliest release gate | Role |
|---|---|---|---|
| Role description / announcement | Public | Always | Candidate |
| Candidate information sheet | Public | Always | Candidate |
| Screening + COI blank forms | Public templates | Screened interest | Candidate |
| Signed COI / confidentiality | Private | After candidate ID assigned | Admin |
| Collaboration terms (UCW-003 voluntary unpaid) | Public wording + private acceptance | UCW-003 RESOLVED | Candidate |
| Public orientation (protocol excerpts) | Public | Confidentiality completed | Candidate |
| Training package | Restricted project | Onboarding gates 1–7 | Candidate |
| Qualification package | Restricted | Training completion recorded | Candidate |
| Qualification answer keys | Private admin only | Never to candidate | Scorer/Admin |
| Calibration / FNSS coding pack | Restricted | Coder READY | Qualified coder |
| Sealed target package | Sealed → Open | READY + calibration authorization | Qualified coder |
| Full corpus (copyrighted) | Restricted local | Corpus freeze + coding gate | Qualified coder |
| Other coder values | Private | After reliability archive | Adjudicator only as needed |

**Stop:** if any prior gate fails, do not release the next restricted row.
