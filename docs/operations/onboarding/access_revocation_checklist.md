# Access revocation checklist

Use when a candidate withdraws, fails finally, or an incident occurs.

- [ ] Record event in private admin log  
- [ ] Disable shared links / package access  
- [ ] Confirm sealed target remains SEALED if not READY  
- [ ] Request destruction confirmation for restricted local files  
- [ ] If answer-key exposure suspected: invalidate set per QUAL-ATTEMPT-v1; do not reuse with exposed person  
- [ ] Update execution dashboard  
- [ ] Do not publish personal details
