# Qualification scoring checklist (PI)

- [ ] Confirm submission hash matches received file  
- [ ] Confirm attempt validity (not technical-invalid; not exposure-invalid)  
- [ ] Run frozen scorer only (`QUAL-SCORER-v1`)  
- [ ] Do not show answer key to coder  
- [ ] Record pass/fail and dimension notes privately  
- [ ] Scorer pass is necessary but not sufficient for READY  
- [ ] Apply `qualification_decision_rules.md` before any READY mark  
- [ ] Keep target SEALED unless READY checklist complete
