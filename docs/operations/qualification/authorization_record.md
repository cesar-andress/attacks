# Qualification authorization record (template)

**Policy:** `QUAL-ATTEMPT-v1` (ADOPTED) — maximum **two valid** attempts; second attempt uses a **different** set; **no answer-key disclosure**; answer-key exposure invalidates the affected set; documented technical failures do **not** consume an attempt; second valid failure is final.

| Qualification-set ID | QUAL-SET-v1 (or alternate set if attempt 2) |
| Package checksum (sha256) | |
| Release timestamp (UTC) | |
| Authorized by | |
| Training completion confirmed | Yes / No |
| COI cleared | Yes / No |
| Confidentiality complete | Yes / No |
| Answer-key exposure | No (required) |
| Notes | |

Do not release attempt 2 on the same set version.  
Do not release answer keys to candidates.  
Failed candidates must not receive materials that compromise future qualification sets.
