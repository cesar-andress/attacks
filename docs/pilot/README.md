# Pilot data directory

**NOT_FOR_SUBSTANTIVE_INFERENCE** · **NOT_FOR_BENCHMARK_COMPARISON** · **PROTOCOL_DEVELOPMENT_ONLY**

All files under `data/pilot/` are excluded from final confirmatory analysis unless an explicit post-pilot decision promotes specific lessons into the codebook/protocol (never silent merge of pilot codes into main results).

| File | Role |
|---|---|
| `PILOT_STATUS.txt` | Multi-gate execution status |
| `PILOT_SOURCE_GATE.txt` | Complete-pilot source gate (`PILOT_SOURCE_NO_GO` while P5 blocked) |
| `prescriptive_elements.csv` | Phase A PE units (reference/stems; excerpts gitignored) |
| `coding_coder_A.csv` | Raw primary human coding |
| `coding_coder_B_procedural.csv` | `simulated_procedural_second_pass` (not independent reliability) |
| `coding_adjudicated.csv` | Post-adjudication |
| `disagreement_log.csv` | Qualitative disagreement analysis |
| `amendment_log.csv` | Pilot-driven protocol/codebook amendments |
| `benchmark_dependent_decision_register.csv` | Rules that must wait for P5 |
