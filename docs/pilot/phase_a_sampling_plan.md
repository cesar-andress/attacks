## Selection rule (pre-coding)

Purposive **maximum procedural variation** within ~20–32 PEs across the four L1 documents. Units selected to exercise, where genuinely present:

1. direct action prescriptions;
2. planning requirements;
3. support specifications (named vs generic);
4. assessment language;
5. exercise / testing provisions;
6. revision / lessons-learned language;
7. setting-specific provisions;
8. ambiguous actor assignments;
9. multi-action / multi-option sentences;
10. cross-referenced requirements;
11. likely explicit demand cases;
12. likely entailed demand cases;
13. likely rung-0/1 cases;
14. candidate higher-rung cases **if text supports them** (not presupposed).

**Forbidden selection basis:** choosing passages because they support an anticipated Results argument about the corpus.

## Target size

- 4 L1 documents
- 20–32 PEs total
- Approximately balanced across sources (±2)
