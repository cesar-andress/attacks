## 3. Reason for amendment

1. **Construct-role alignment:** CF-02 is a conceptual journal source; FNSS is operational doctrine suitable for L2 PE unitization.  
2. **Instrument fit:** FNSS supports PE / ladder / locus / demand-source coding.  
3. **Preserves falsification:** RQ4 remains a contrastive comparison with function-based emergency-planning doctrine.  
4. **Transparency:** Change is fully disclosed before confirmatory coding and preregistration.  

Access failure of CF-02 is acknowledged but is **not** the sole justification (OPT-D rejected).

## 4. Exact L1 scope

Complete authorized PDF as candidate text; unitize under the existing L2 PE definition (Appendix/coding rules).  
No outcome-selected chapter whitelist.  
Appendices/tools eligible only if they meet the PE definition.
