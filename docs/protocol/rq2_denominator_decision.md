# RQ2 denominator decision

**Decision date:** 2026-07-31  
**Status:** resolved for analysis planning  
**RQ2 (concept):** Where documentary engagement occurs, what is its locus?

## Options evaluated

| Option | Definition | Validity for RQ2 wording | Denominator bias risk | Codebook fit |
|---|---|---|---|---|
| A | All eligible PEs | Weak: includes non-engagement | Hides “where engagement occurs” signal in `not_specified` mass | Compatible |
| **B** | **PEs with `executability_rung` ≥ 1** | **Strong: matches “where engagement occurs”** | Conditional on any prescription-level engagement | Compatible (E1/E2) |
| C | Only rungs 2–5 | Too narrow; drops prescription-only engagement | Overstates depth among supports+ | Compatible but misaligned to RQ2 |
| D | Document-level aggregation | Different estimand; loses PE locus | Ecological fallacy risk | Possible secondary |
| E | Framework-level aggregation | Different estimand | Same | G-family adjacent, not E2 |

## Firm recommendation

**Primary estimand (RQ2):** option **B** — locus distribution among L2 prescriptive elements with `executability_rung ≥ 1`.

**Complementary estimand (transparency):** option **A** — joint rung × locus table over **all** eligible PEs, which makes non-engagement (rung 0) visible and prevents the conditional table from being misread as corpus-wide locus coverage.

Do **not** use option C as the RQ2 primary denominator.

Document- or framework-level locus summaries (D/E), if reported, are secondary displays only and must be labeled as such.

## Reporting rule

1. Table RQ2-primary: locus % among rung ≥ 1.  
2. Table RQ2-complement: full rung × locus counts (all PEs).  
3. Never interpret `not_specified` at rung 0 as a positive locus claim.

## Manuscript / prereg

Analysis plan and manuscript RQ/methods text must state both estimands; primary answers RQ2.
