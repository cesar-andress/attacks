# Future-work claims policy

**Scope:** How the programme may describe planned work and partially validated products.  
**Companion:** Paper 1 documentary claims remain governed by `docs/protocol/claims_policy.md`.

## Permitted language (pre-validation / planning)

- will inform  
- provides a basis for  
- is intended to support development  
- requires field validation  
- is a candidate domain  
- remains to be tested  
- planned / provisional / unvalidated  

## Prohibited language (before the relevant validation stage)

- validated instrument (before RP-P3 criteria)  
- predicts attacks  
- prevents attacks  
- identifies dangerous students  
- measures actual readiness solely from documents  
- demonstrates effectiveness (Layer 5)  
- proves one school type is more vulnerable  
- provides a comprehensive risk score / inclusive-security score  

## Claims permitted after staged evidence

| Stage reached | Permitted claim form |
|---|---|
| Content validity only (RP-P2) | “Indicators were judged relevant by experts for organisational domain X; field validation is still required.” |
| Pilot reliability only | “In a small pilot, internal consistency/inter-rater met pre-specified thresholds; generalisation remains limited.” |
| Structural / construct validation (RP-P3) | “Domain structure was consistent with the specified model in sample S for stated uses.” |
| Intervention evaluation (later) | “Intervention targeting domain X changed measured organisational indicators under design D” — still not attack prevention unless separately evidenced. |

## Cross-paper reminders

- RP-P1 findings are Layer 1 only.  
- SLAPA Domain B claims follow RP-P4 / detectability rules; never demand–capability fit.  
- No single total preparedness rank at any stage.
