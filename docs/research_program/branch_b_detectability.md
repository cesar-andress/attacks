## Explicit non-implications

- More reporting, monitoring, or surveillance does **not** automatically improve safety.  
- Absence of a false-positive safeguard in a document is **not** endorsement of over-referral.  
- Disability-related behaviour must never be treated as a proxy for dangerousness.  
- Domain B must never be averaged with Domain D into an inclusive-security score.
