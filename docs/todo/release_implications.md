# Release implications of unresolved items

| Release | Blocked by unresolved items? | Verdict |
|---|---|---|
| Methodological pre-release (v0.1–v0.4 lineage) | Transparently documented P0 source/freeze NO_GOs are **allowed** | **Ready as methodology** if no false completeness claims |
| v0.2+ experimental pack | Human EXP not executed | **Ready as synthetic pack**; not human-validated |
| Preregistration release | TODO-PRE-001, freeze, complete pilot | **NOT ready** |
| Corpus-freeze release | TODO-FRZ-001, SRC-*, Phase B | **NOT ready** |
| Manuscript submission | MAN corpus N, prereg ID, Results/Discussion/Conclusion, empirical α | **NOT ready** |

A methodological release may contain blocked empirical tasks when they are registered, gated, and do not invalidate released artifacts.
