# Validation contract

Passing `make release-check` means:

1. Metadata/coding/pilot/research-programme validators succeed.  
2. Experimental pack validators succeed.  
3. Full pytest suite passes.  
4. Synthetic experiment analyses run and refuse prohibited claims (α from procedural pass; total SLAPA score; human-executed status).

It does **not** mean:

- human experiments were executed;  
- SLAPA is validated;  
- documentary corpus is frozen;  
- complete pilot is finished.
